# CN-Project-HNWPQ-
This project, detailed in Hospital_Network_QoS_Project_Guide.docx, features a Cisco Packet Tracer design prioritizing life-critical medical data. It uses Priority Queuing to ensure ICU and VoIP traffic bypass congestion. With 8 VLANs, MQC-based QoS, and NAT, it balances medical urgency with secure guest access.
